# ASTRA BioTelemetry Simulation UI

A responsive, front-end-only dashboard prototype based on the supplied visual reference.

## Files
- `index.html` — dashboard structure
- `styles.css` — responsive dark sci-fi interface
- `app.js` — simulated vital telemetry, charts, ECG trace, alert/pause controls, system inspection modal
- `assets/human-monitor-reference.png` — your uploaded reference image used in the central body-scan panel

## Run locally
Open `index.html` in a modern browser. No build step or package installation is required.

## Use in Google Antigravity
1. Extract this ZIP into your project folder.
2. Open that folder in Antigravity.
3. Ask the agent to integrate the existing ASTRA dashboard into your app while preserving the file structure.
4. Keep `assets/human-monitor-reference.png` in the `assets` folder so the image path resolves.

## Important
All values and charts are simulated demo data. This is a UI prototype only, not a medical device, astronaut life-support controller, or flight-certified monitoring system. Do not connect it to real hardware or use it for health decisions.
